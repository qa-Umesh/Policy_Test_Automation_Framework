# UL Policy Automation Framework

A Java-based Selenium Automation Framework developed for validating UL (Unit Linked) Insurance Policy data across different policy scenarios.

The framework follows the Page Object Model (POM) design pattern and uses TestNG for test execution. It supports data-driven testing through Excel files and automates policy validation workflows including Performance Snapshot and Future Performance calculations.

The framework is designed to improve validation accuracy, reduce manual effort, and provide a scalable foundation for future automation enhancements.

## Installation

Clone the repository:

```bash
git clone https://github.com/qa-Umesh/Policy_Test_Automation_Framework.git
```

Move to project directory:

```bash
cd Policy_Test_Automation_Framework
```

Install dependencies:

```bash
mvn clean install
```

---

## Execute Tests

```bash
mvn clean test
```

or execute through:

```bash
testng.xml
```
